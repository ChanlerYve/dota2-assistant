## 1. 这份手册能帮你做什么

**它解决的问题**：选人阶段时间很紧，你需要在一分钟内从「我会玩的英雄」里挑出
「这局最好发挥的那个」，而且要知道**为什么**。

**它给出的东西**：一张按分数排序的推荐表，每一项都能拆开看——

```
1.  Axe                  ★★★★☆  评分  70.8  位置 3
      熟练 0.76 | 对位 0.50 | 阵容 1.00 | 版本 0.41 | 配合 0.50
      · 你擅长：你打 3 号位 32 局，胜率 59%（位置熟练度贡献 24.3 分）
      · 克制: Juggernaut(+4%)（对位贡献 12.2 分）
      · 阵容：补先手（全队此项缺口 60%）（阵容贡献 21.6 分）
      · Divine 段胜率 48.6%（63,259 场）（版本强度贡献 6.4 分）
      ! Axe 打不了 5 号位（它只能打 3 号位） (-15%)
```

**它做不到什么**（先看这段，避免误期待）：

| 你可能期待 | 实际情况 |
|---|---|
| 自动读取游戏里的 BP | ❌ 不行。GSI 在天梯 All Pick 下不推送 draft，读屏有封号风险。**必须你手动/语音录入**，详见 [§15](#15-安全与合规) |
| 「选它就有 X% 胜率」 | ❌ 没有这种数字。0-100 分是**同一局内候选之间的相对排序**，不是胜率 |
| 全自动帮你想出所有英雄 | ❌ 只在**你英雄池里**挑（可用 `all` 命令看全英雄视角，但那不含你的熟练度） |
| 替你看对手是不是代练/小号 | ❌ 不涉及任何玩家画像，只做英雄层面的推荐 |

## 2. 安装与首次启动

### 环境要求

- **Python 3.9+**（Windows 官方安装包自带 tkinter，悬浮窗需要它）
- **零第三方依赖**——不需要 pip install 任何东西
- 联网可选：只在刷新数据与导入英雄池时需要

### 确认能跑起来

```powershell
cd dota2-assistant

# 1) 全链路自检：数据、引擎、Web API、语音、悬浮窗依赖
python tools/selftest.py

# 2) 看效果：跑一个仿真对局（不需要配置任何东西）
python -m d2a --demo
```

自检最后一行应该是 `自检全部通过 ✅`。如果报错，先看 [§13 故障排查](#13-故障排查)。

### 第一次启动悬浮窗

```powershell
python -m d2a
```

**重要**：Dota 2 必须设置成**无边框窗口（Borderless Windowed）**，
否则全屏独占模式下 Windows 不允许任何置顶窗口覆盖画面。这也是职业比赛的常规设置。

## 3. 第一步：建立你的英雄池

> **这一步决定推荐质量的 70%。** 英雄池为空时，悬浮窗只会提示你先添加英雄。

三种方式，任选其一（可以混用）：

### 方式 A：从公开战绩自动导入（最省事）

```powershell
python -m d2a --steam <你的 Steam32 位 ID>
```

- 支持 32 位 ID、64 位 ID、`STEAM_0:1:xxxxx`、个人主页链接
- **前提**：账号已开启 Dota 2 设置里的 **Expose Public Match Data**（公开比赛数据），否则读不到
- 导入结果会写入 `config.json`

### 方式 B：手工写配置文件

复制样例后编辑：

```powershell
copy config.example.json config.json
```

```json
{
  "pool": {
    "Axe": [60, 37],
    "Crystal Maiden": [88, 50],
    "Lion": 52
  }
}
```

格式说明：

| 写法 | 含义 |
|---|---|
| `"Axe": [60, 37]` | 60 局，37 胜 |
| `"Lion": 52` | 52 局，胜率按 50% 保守处理 |
| `"斧王": [60, 37]` | **中文名也认**（还有缩写、绰号，见 [§7](#7-录入-bp-的写法)） |

### 方式 C：界面里逐个加

- **命令行**：`pool add 斧王 60 37`
- **浏览器面板**：右侧「我的英雄池」里填

### 方式 D：赛后同步（推荐长期使用）

不用你手动统计，直接读你真实对局并**按位置**记战绩：

```powershell
python tools/sync_results.py --account-id <Steam32位ID> --limit 20 --probe   # 先看
python tools/sync_results.py --account-id <Steam32位ID> --limit 20           # 再写
```

详见 [§11](#11-每周维护赛后同步与数据刷新)。

## 4. 日常使用：一局游戏的完整流程

```
① 进游戏，BP 开始
       ↓
② 按 Ctrl+Alt+V（或点 🎤）开口说英雄名，或直接键盘敲
       ↓
③ 悬浮窗实时更新推荐（每 0.5 秒自动刷新）
       ↓
④ 看第一条推荐的理由，判断是否采纳
       ↓
⑤ 打完几局后跑一次 sync_results.py，英雄池自动跟上
```

### 录入选人的实际操作

悬浮窗底部的输入框**接受中英文、缩写、绰号**，回车即录入：

| 你想录入 | 可以直接敲 | 说明 |
|---|---|---|
| 敌方选了主宰 | `剑圣` / `jugg` / `juggernaut` / `主宰` | 四种写法都认 |
| 我方选了水晶室女 | `冰女` / `cm` / `crystal maiden` | |
| 敌方选了噬魂鬼 | `ls` / `小狗` / `naix` / `lifestealer` | |
| 打错了想撤销 | `rm 剑圣` | |
| 记一个 ban | 先把输入框左侧切到「ban」（点一下切换），再敲英雄名 | |
| 整局重来 | 输入 `reset` 或 `清空` | |

输入框左侧那个彩色小块是**阵营切换**：点一下在 `敌 → 我 → ban` 之间循环。

### 指定你要打的位置

悬浮窗顶部有 `1 2 3 4 5 自动` 六个按钮。

- **不确定就点「自动」**：助手会按**你的英雄池**推断你常打几号位
  （辅助池→5 号位，核心池→1/2/3），而不是死板地当 1 号位
- 标了位置后，**打不了这个位置的英雄会被明确扣分**并在理由里说明
  （如 `Axe 打不了 5 号位（它只能打 3 号位） (-15%)`）

## 5. 三种界面怎么选

| 界面 | 启动 | 适合 | 特点 |
|---|---|---|---|
| **悬浮窗** | `python -m d2a` | 游戏内使用 | 置顶半透明，可鼠标穿透，有语音按钮；需无边框窗口模式 |
| **浏览器面板** | `python -m d2a --web` | 双屏 / 手机 / 悬浮窗被挡时 | 可拖权重滑块、看分位置战绩、一键复制解释、有档位下拉框 |
| **命令行** | `python -m d2a --cli` | 快速查询 / 脚本化 | 最轻量，功能最全（含 `bracket`、`voice`） |

三者的推荐结果**保证一致**（共用同一个引擎），只是呈现方式不同。

### 悬浮窗快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+D` | 显示 / 隐藏悬浮窗 |
| `Ctrl+Alt+T` | 切换鼠标穿透（穿透后只能用快捷键恢复） |
| `Ctrl+Alt+V` | 开 / 关语音录入 |
| 拖动标题栏 | 移动窗口位置 |
| 「详情」按钮 | 展开完整因子、理由、风险 |

### 浏览器面板的额外能力

- **权重滑块**：拖动即时生效
- **分位置战绩表**：「我的英雄池」里每个英雄会显示 `3号 59%(32) · 4号 48%(15)`
- **天梯档位下拉框**：右上角，切换高分段切片
- **详细解释**：每张卡片上的按钮，弹出含**各因子贡献分值**的完整说明

## 6. 语音录入 BP

### 先做自检

```powershell
python -m d2a --voice-probe --voice-seconds 6
```

对着麦克风念「斧王」「剑圣」，期望看到：

```
语音自检：监听 6 秒，模式 hero。请对着麦克风念英雄名（如「斧王」「剑圣」）…
  [就绪] zh-CN hero
  [听到] 斧王  (0.91)
共识别到 1 条语音。
```

### 三种开启方式

| 方式 | 操作 |
|---|---|
| 悬浮窗 | 点标题栏 🎤 按钮，或按 `Ctrl+Alt+V` |
| 浏览器面板 | 点右上角「🎤 语音」按钮 |
| 命令行 | 输入 `voice`（默认 6 秒）或 `voice 10`（10 秒） |

再次按 `Ctrl+Alt+V`（或再点一次按钮）即停止。

### 识别原理与预期

- 用 **Windows 自带语音识别**，**离线、不联网、不上传音频、不需要 API Key**
- 识别范围被**约束成英雄名 + 别名**（500 多条），所以「斧王」「剑圣」「jugg」都能认，
  准确率远高于自由听写
- 识别出的文本走**与键盘输入完全相同**的解析管线——所以别名、中文名、缩写全部生效
- 置信度低于 0.55 会被丢弃并提示「没听清」，不会乱录
- 同一句话 1.5 秒内的重复识别会被忽略，避免一次说话录进去两次

### 识别不出来怎么排查

按这个顺序查（**第 1 条是最常见原因**）：

1. **Windows 设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问**
2. 设置 → 系统 → 声音 → 默认输入设备是否选对
3. 设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项 → **语音包**是否已安装
4. 说话时离麦克风近一点，念**完整的英雄名**（「斧王」比「斧」好）

自检输出会明确区分两类失败：

- `识别引擎没能创建成功` → 环境问题（语音包缺失，或进程无法访问音频设备）
- `没有识别到内容（引擎正常，可能是没听到）` → 麦克风/设备问题

### 想自由说话？

```powershell
python -m d2a --cli
> voice 8 dictation
```

或在 `config.json` 里把 `voice.mode` 改成 `"dictation"`。
**注意**：自由听写模式下识别范围不再受约束，准确率会明显下降。

### 参数配置

`config.json` 里的 `voice` 段：

```json
"voice": {
  "enabled": false,        // true = 开悬浮窗就开始听
  "culture": "",           // 留空自动优先中文；也可写 "en-US"
  "mode": "hero",          // hero（推荐）| dictation
  "min_confidence": 0.55,  // 低于此置信度丢弃
  "seconds": 0,            // 0 = 一直听，直到再按一次热键
  "auto_add": true         // false = 只提示不录入
}
```

## 7. 录入 BP 的写法

**英雄名解析支持四级匹配**，命中优先级从高到低：

| 级别 | 例子 |
|---|---|
| 1. 别名表（527 条） | `剑圣`→Juggernaut、`jugg`→Juggernaut、`ls`→Lifestealer、`wisp`→Io、`abba`→Abaddon、`dusa`→Medusa、`qop`→Queen of Pain |
| 2. 官方全名 | `Juggernaut`、`Crystal Maiden` |
| 3. 前缀 / 包含 | `sni`→Sniper、`shaker`→Earthshaker |
| 4. 模糊匹配（容错拼写） | `medusaa`→Medusa、`lichh`→Lich |

命中多个时会用**出场率**消歧（取更常见的那个），所以 `ls` 稳定落到 Lifestealer 而不是 Vengeful Spirit。

**大小写、空格、连字符都不敏感**：`crystal maiden` = `CrystalMaiden` = `CRYSTAL-MAIDEN`。

### 自己加别名

编辑 `data/aliases.json`（格式 `"别名": "官方英文名"`），加完立即生效，不用改代码：

```json
{
  "我老婆": "Crystal Maiden",
  "狗子": "Lifestealer"
}
```

注意：别名归一化后**不能重复**，且必须指向 `data/heroes.json` 里存在的官方名。
加错了不会崩，只是那条不生效。

## 8. 看懂推荐结果

### 每张卡片的三层信息

```
1.  Axe                  ★★★★☆  评分  70.8  位置 3     ← ① 总分与星级
      熟练 0.76 | 对位 0.50 | 阵容 1.00 | 版本 0.41 | 配合 0.50   ← ② 五因子原始分
      · 你擅长：你打 3 号位 32 局，胜率 59%（贡献 24.3 分）      ← ③ 理由（按影响力降序）
      ! Axe 打不了 5 号位（它只能打 3 号位） (-15%)             ← 风险/扣分项
```

- **① 总分**：0-100，只在同一局内比较，不是胜率
- **② 五因子**：每个都在 0~1，越接近 1 越好
- **③ 理由**：每条都标了**它给总分贡献了多少分**，加起来等于加权总分（可对账）

**低置信标注**：如果某条理由后面带「（低置信）」，说明它对分数的影响小于 2 分，
别太当真。

### 五个因子分别是什么意思

| 因子 | 白话 | 什么时候会低 |
|---|---|---|
| **熟练度** | 你会不会玩（**按位置算**） | 玩得少、胜率低、这个位置没打过 |
| **对位** | 打不打得过对面 | 被对面多个英雄克制（同路敌人权重最高） |
| **阵容** | 补不补得上队伍短板 | 队伍不缺你这类英雄，或位置排不下 |
| **版本** | 这个版本强不强 | 该英雄胜率低于 50%（切了档位就用该档位数据） |
| **配合** | 和队友有没有组合技 | 该英雄没有协同数据（此时**不计入权重**，不会假装中性） |

### 扣分项（风险）怎么读

括号里是**扣分百分比**，总扣减有 30% 上限（避免把候选一棒子打死）。常见项：

| 风险提示 | 含义 |
|---|---|
| 全队缺少先手，团战开不起来 | 你们没人能开团 |
| 全队几乎没有硬控，留不住人 | 缺控制，抓不死人 |
| 敌方物理输出多，我方缺前排 | 会被顶着打 |
| 敌方推进强，我方清线不足 | 会被兵线拖死 |
| 你没玩过这个英雄，纯靠版本/克制硬选 | 不在英雄池里 |
| 熟练度偏低，需要手感局 | 熟练度 < 0.35 |
| 和我方已选位置冲突，排不下 | 位置重叠 |
| **XX 打不了 N 号位（它只能打 M 号位）** | **位置不匹配，最该重视的一条** |

## 9. 调参：让推荐符合你的风格

### 权重是干什么的

总分是五个因子的加权和。默认权重：

| 因子 | 默认 | 调高会怎样 |
|---|---|---|
| 熟练度 | **0.32** | 更倾向「你玩得好的」，哪怕版本弱 |
| 对位 | 0.22 | 更倾向「克制对面的」 |
| 阵容 | 0.22 | 更倾向「补队伍短板的」 |
| 版本 | 0.14 | 更倾向「版本强势的」 |
| 配合 | 0.10 | 更倾向「和队友有组合的」 |

### 三种调整方式

**① 浏览器面板拖滑块**（最直观，即时生效）

**② 命令行**

```
w prof 0.45        # 熟练度权重调到 0.45（会自动归一化，不用你算总和）
w match 0.15
```

键名：`prof` / `match` / `team` / `meta` / `syn`

**③ 编辑 `config.json`**

```json
"weights": { "proficiency": 0.45, "matchup": 0.15, "team_need": 0.25, "meta": 0.10, "synergy": 0.05 }
```

### 推荐的三套预设

| 风格 | 配置 | 适合 |
|---|---|---|
| **绝活型** | `prof 0.50 / match 0.20 / team 0.15 / meta 0.10 / syn 0.05` | 英雄勺很深，就想打好自己会的 |
| **稳健型**（默认） | `0.32 / 0.22 / 0.22 / 0.14 / 0.10` | 兼顾会玩与阵容 |
| **阵容型** | `prof 0.25 / match 0.25 / team 0.35 / meta 0.10 / syn 0.05` | 队友都很会玩，优先补阵容 |

> 权重会自动归一化（总和恒为 1），所以你写 `0.5 / 0.5` 也行。

## 10. 切天梯档位看版本答案

### 为什么需要

**全体平均会掩盖版本答案。** 同一个英雄在不同分段强弱可能相反。实测当前数据：

| 英雄 | 全体 | Crusader | Legend | Divine |
|---|---|---|---|---|
| Axe | 50.6% | **51.6%** | 50.0% | **48.6%** |
| Anti-Mage | 50.8% | 51.1% | 50.5% | 51.3% |

而且**全体胜率前 10 与 Divine 段前 10 只重合 5 个**。

### 怎么切

**命令行**：

```
bracket              # 看当前切片 + 各档位对比
bracket divine       # 切到 Divine（也认 7 / 超凡 / immortal）
bracket ancient      # 切到 Ancient
bracket all          # 回全体平均
```

**浏览器面板**：右上角下拉框。

**配置文件**：

```json
"bracket": "divine"
```

**档位编号对照**（也认中文）：

| 编号 | 英文 | 中文 |
|---|---|---|
| 1 | Herald | 先锋 |
| 2 | Guardian | 守卫 |
| 3 | Crusader | 中军 |
| 4 | Archon | 统帅 |
| 5 | Legend | 传奇 |
| 6 | Ancient | 神话 |
| 7 | Divine | 超凡 |
| 8 | Immortal | 冠绝 |

> **注意**：OpenDota 公开数据里 **Immortal(8) 档位恒为 0**，所以 UI 只给到 7(Divine)。
> 想看真正的顶分局/职业切片需要接 STRATZ（见 README 第 8 节）。

切了档位后，推荐理由会变成 `Divine 段胜率 48.6%（63,259 场）`，明确告诉你数据出处。

## 11. 每周维护：赛后同步与数据刷新

### 11.1 赛后同步（让熟练度跟上你的真实状态）

**每次打完几局跑一次**：

```powershell
# 第一步：先看会同步什么，不写文件
python tools/sync_results.py --account-id <你的Steam32位ID> --limit 20 --probe

# 第二步：确认无误后正式写入
python tools/sync_results.py --account-id <你的Steam32位ID> --limit 20
```

也可以直接用 64 位 ID 或主页链接：

```powershell
python tools/sync_results.py --steam 76561198xxxxxxxxx --limit 30
python tools/sync_results.py --steam https://steamcommunity.com/id/xxxx --limit 30
```

**它会做什么**：

```
英雄池: 5 个英雄（来自 config.json）
水位: 9022301512；列表返回 6 局
本次同步到 6 局，涉及 5 个英雄：
  Keeper of the Light  2 局 1 胜  位置: 2
  Necrophos            1 局 1 胜  位置: 1
  （其中 1 局没有位置数据——旧对局常未被解析，只计总体战绩）
已回写英雄池 → config.json
```

**关键特性**：

- **增量**：记录 `match_id` 水位，重复运行不会重复计数（会提示「跳过 N 局已处理的」）
- **分位置**：用 OpenDota 的 `position_est` 拿到 1~5 号位，写进 `by_lane`
- **不编数据**：未解析的对局没有位置信息，就只计总体战绩，不会瞎猜一个位置

**注意**：

- 每局详情是**一次 API 请求**（免费额度 60/分钟、3000/天），所以 `--limit` 别设太大；
  已缓存的比赛不会重复请求
- 需要账号开启 **Expose Public Match Data**，否则会提示「这个账号没有公开对局」

### 11.2 数据刷新（版本更新后）

```powershell
# 快：只更新版本胜率 + 档位数据 + 版本号
python tools/refresh_data.py --meta

# 慢：同时拉真实对位（127 次请求，约 3 分钟）
python tools/refresh_data.py --meta --matchups

# 只用本地缓存重建（不联网）
python tools/rebuild_meta.py
python tools/rebuild_matchups.py
```

**大版本更新后建议跑一次 `--meta`**，否则版本强度数据会过期。
数据面板会显示当前版本号（如 `7.41`），可以据此判断新旧。

## 13. 故障排查

### 先跑自检

```powershell
python tools/selftest.py
```

它会逐项报告数据、引擎、Web API、语音、悬浮窗依赖是否正常，多数问题能直接定位。

### 悬浮窗盖不住游戏画面

- **原因**：Dota 2 处于全屏独占模式
- **解决**：游戏设置 → 视频 → 显示模式 → 改成 **无边框窗口（Borderless Windowed）**

### 悬浮窗点不到（鼠标穿不过去 / 挡住了操作）

- 按 `Ctrl+Alt+T` 切换鼠标穿透
- 穿透后窗口不再接收鼠标，只能再用快捷键恢复

### 提示「认不出这个英雄」

- 检查拼写；也可用中文名（`斧王`）或缩写（`am`、`sf`）
- 确认该英雄在 `data/heroes.json` 里（比如刚出的新英雄可能还没收录）
- 想加自己的叫法：编辑 `data/aliases.json`（见 [§7](#7-录入-bp-的写法)）

### 推荐列表是空的 / 提示英雄池为空

- 说明英雄池还没建：见 [§3](#3-第一步建立你的英雄池)
- 如果用 `rec` 命令，它默认只看英雄池；想看全英雄用 `all`

### 语音识别完全没反应

按 [§6 语音录入 BP](#6-语音录入-bp) 里的四步排查，**第一优先检查麦克风权限**。

如果是 `识别引擎没能创建成功`，说明系统语音组件不全；本机实测需要装中文语音包：
设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项 → 语音。

### 版本数据看起来是旧的

- 看数据面板显示的版本号（如 `7.41`）
- 跑 `python tools/refresh_data.py --meta` 更新
- 只想重建不想联网：`python tools/rebuild_meta.py`

### 某个英雄没有对位数据 / 推荐里看不到克制关系

- 正常情况下**全部 127 个英雄都有对位数据**（可跑 `selftest.py` 确认）
- 若确实缺失，跑 `python tools/refresh_data.py --matchups` 或 `python tools/rebuild_matchups.py`

### 赛后同步提示「没有公开对局」

- 需要在 Dota 2 里开启 **Expose Public Match Data**（设置 → 社交 → 公开比赛数据）
- 确认 ID 没写错（32 位与 64 位差很多，助手的解析器认几种常见格式）

### 网络相关

- 拉数据失败通常是网络问题：`api.opendota.com:443` 要能通
- 加了 `OPENDOTA_API_KEY` / `STEAM_API_KEY` 环境变量可提高限额（都不是必需）

### 文件位置

| 文件 | 位置 |
|---|---|
| 配置文件 | 优先 `--config`，其次项目下 `config.json`，再次 `%APPDATA%\dota2-assistant\config.json` |
| 数据缓存 | `data/cache/`（可安全删除，删了会重新拉） |
| 英雄别名 | `data/aliases.json` |

## 14. 常见问题

**Q：分数 70 分是不是意味着 70% 胜率？**
A：不是。0-100 是同一局内候选之间的相对排序。70 分的 Axe 比 60 分的 Lion 更值得选，
但「70」本身没有绝对含义。

**Q：为什么某英雄（如 Meepo）明明很强，推荐里却没有？**
A：因为**你英雄池里没有它**。默认只在「你打过的英雄」里推荐。
想看不含熟练度的纯版本/克制视角，用 `all` 或 `counter` 命令。

**Q：为什么推荐了 5 号位打不了的英雄？**
A：默认**不过滤**，而是给显式扣分并标注（`打不了 N 号位 (-15%)`），
这样你能看到完整候选并理解原因。想彻底过滤，Web API 支持 `strict_lane=1`。

**Q：位置推断（敌方几号位）准吗？**
A：是启发式。它按英雄标签 + 先手顺序 + 阵容结构做全局最佳分配，比「第几手固定猜第几个位置」
准得多，但仍会错。发现不对可以手动改位置（UI 里可点）。

**Q：能不能不联网用？**
A：可以。英雄库、别名表、克制矩阵全部内置。只有「刷新数据」和「导入真实战绩」需要联网。

**Q：数据会上传吗？**
A：不会。所有数据留在本机。Web 面板只监听 `127.0.0.1`，语音识别完全离线。

**Q：换电脑怎么迁移？**
A：复制 `config.json`（含英雄池与权重）即可。`data/` 里的内置数据不用带。

**Q：为什么 Immortal 档位是灰的/没数据？**
A：OpenDota 公开数据的 Immortal 档位恒为 0，最高只能到 Divine(7)。

**Q：为什么「配合」这个因子总是 0.50？**
A：协同数据只覆盖 35 个英雄。没有该英雄的协同数据时，这个因子**不计入权重**
（权重会让给其他因子），而不是假装成中性 0.5。

**Q：改了 traits / 别名要重启吗？**
A：别名改 `data/aliases.json` 后**重启生效**；英雄标签改 `tools/gen_hero_data.py`
后要跑一次 `python tools/gen_hero_data.py` 重新生成。

## 15. 安全与合规

### 助手的技术行为边界

本工具在所有方面等同于「**一个置顶备忘录 + 计算器 + 输入法**」：

- ❌ 不注入 DLL、不 hook 游戏进程、不读写游戏内存
- ❌ 不抓包、不拦截网络、不调用游戏内部接口
- ❌ **不做屏幕 OCR / 图像识别**（尤其不读游戏画面判断 BP）
- ❌ 不模拟键鼠，没有任何自动操作
- ✅ 只读公开 HTTP 接口（OpenDota / Valve WebAPI）+ 本地静态数据
- ✅ 输入完全来自你自己的键盘或麦克风

因此它**不会触发 VAC**——VAC 关注的是对游戏进程与内存的干预。

### 为什么必须手动录入 BP（而不是自动读取）

这是一个经过调研的技术判断，不是偷懒：

1. **GSI 在天梯给不了 draft**。Valve 官方 issue 确认 GSI 的 `draft` 字段只有 CM 模式有；
   请求「天梯也开放」的 issue 从 2024 年挂到现在未解决。
2. **Overwolf 靠的是白名单特权**。它读内存是因为和 Valve 有协议，普通开发者复现不了；
   而它的官方事件列表里也**没有任何 draft/pick 事件**。
3. **Valve 的措辞覆盖「读客户端数据」**，并且在 2023-02 用**蜜罐**主动封禁了 4 万个
   「读客户端秘密数据」的账号，同一次更新还专门堵掉了选人阶段的信息读取。
4. **读屏是灰色地带**。即便只 OCR 不读内存，Valve 未点名但也未批准；
   STRATZ+ 用 OCR 做的选人助手在 2023-02 主动停运。
   社区里自述用 OCR 做这件事的开发者评价是「buggy/slow and not good」。

**结论**：语音在这里只被当作**输入法**——把你说的话变成文本，再走与键盘相同的解析管线。
它不读游戏画面、不感知 BP，所以合规边界和手打录入完全一样。

- 如果某场比赛/赛事的规则明确禁止外部辅助，请遵守赛事规则
- 尊重上游 API 的限流与条款（OpenDota 免费 60/分钟、3000/天）
